# Student Management System

About the Project

The Student Record Management System is a CLI-based Java application for managing student records.
This project was created as part of a Java Developer Internship Task.

Features

- Add a new student
- View all student records
- Update student details
- Delete a student record
- Prevent duplicate student IDs
- Exit the application through the menu

Technologies Used

- Java
- ArrayList
- Scanner
- VS Code / Jvdroid

Concepts Used

- Classes and Objects
- Encapsulation
- ArrayList
- Loops
- Conditional Statements
- Methods
- Getters and Setters
- CRUD Operations

Student Details

Each student record contains:

- Student ID
- Student Name
- Student Marks

How to Run

1. Open "StudentRecordManagement.java" in a Java-supported IDE or Jvdroid.
2. Compile and run the program.
3. Use the menu options to Add, View, Update, or Delete student records.
